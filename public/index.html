🔑 Hướng Dẫn Cấu Hình OAuth

1. Cấu hình Google Cloud (Gmail Login)

Truy cập Google Cloud Console → APIs & Services → Credentials:

  • Chọn Create Credentials → OAuth Client ID
  • Application type: Web application
  • Authorized redirect URIs điền chính xác:
http://localhost:3000/auth/google/callback

Sao chép Client ID và Client Secret dán vào file .env.

2. Cấu hình GitHub OAuth App

Truy cập GitHub → Settings → Developer Settings → OAuth Apps:

  • Bấm New OAuth App
  • Homepage URL: http://localhost:3000
  • Authorization callback URL điền:
http://localhost:3000/auth/github/callback

Tạo Client Secret và dán vào file .env.

3. Cập nhật file .env và Khởi động lại 

GOOGLE_CLIENT_ID=your_google_client_id_here
GOOGLE_CLIENT_SECRET=your_google_client_secret_here

GITHUB_CLIENT_ID=your_github_client_id_here
GITHUB_CLIENT_SECRET=your_github_client_secret_here
